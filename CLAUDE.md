# Working in this repository

A bilingual static portfolio. Read `README.md` first for the run commands.

## The one rule

**Never edit `*.html`, `en/*.html`, `cv/`, `resume/`, `profile/`, `llms*.txt`,
`sitemap.xml`, or `api/*.json` by hand.**
They are generated by `scripts/build.mjs` and your changes will be destroyed on the next
build. Edit `data/` instead, then run `npm run build`.

## Where facts live

Every fact appears in `data/` exactly once:

| File | Holds |
|---|---|
| `data/profile.json` | Identity, contact, the `sameAs` link graph, availability |
| `data/experience.json` | Employment, newest first |
| `data/projects.json` | Products and applications |
| `data/workflows.json` | n8n automations |
| `data/credentials.json` | Certifications, education, awards |
| `data/testimonials.json` | Recommendations |
| `data/skills.json` | Skills by category |
| `data/copy/{en,ar}.json` | All prose, both languages, identical key sets |

## Content rules, enforced by tests

These are not style preferences — `npm test` and `npm run validate` fail on them:

- The product is **Smart Scanner**, never "Receipt Scanner".
- **Alessa Group must not appear anywhere.** Smart Scanner is presented as Nour's own
  product work with no employer named.
- His base is **Al Khobar**, never Riyadh. (Khwarizm Technologies was Riyadh-remote —
  that one is correct as written.)
- Arabic and English copy must expose **identical key sets** and equal array lengths.
- Unknown facts are `null` with a sibling `todo` string. They must never render as a link.
- Prose contains **no figures** — every number comes from `data/` so it cannot drift.

## Code conventions

- ES modules everywhere. Node's built-in test runner only (`node --test`); no framework.
- CSS uses **logical properties** (`margin-inline`, `inset-inline-start`) so the Arabic
  RTL mirror needs almost no overrides. Never write `left:` or `right:`.
- `scripts/lib/*.mjs` are pure transforms — data in, string or object out. Keep them
  side-effect free so they stay unit-testable.
- `mcp/tools.js` is pure; `mcp/server.js` is protocol wiring only. Do not mix them.
- `assets/js/chat/engine.js` knows nothing about Nour; `script.*.js` knows nothing about
  rendering.
- **No JavaScript may render user-facing content.** Everything must be in the HTML
  before scripts run — that is the entire premise of this rebuild.

## Before committing

```bash
npm run check    # test → build → validate
```

`validate` exits non-zero on errors. Warnings about pending GitHub/FIDE/portrait links
are expected until those are supplied.
