Universal Web Scraper

Website scraper that turns a whole site into an Excel file

AI automation product2026

One link in, the whole site out: every page discovered, the data classified, and an Excel file with a tab for each kind of data.

The problem

Collecting data from websites usually means copying it by hand into Excel, or writing a new scraper for every site, which breaks the moment a site blocks bots or renders its content with JavaScript.

What I built

You paste one link. The engine discovers every page of the site through its sitemap, classifies what it finds (companies, people, products, articles, jobs, places) and fills an Excel file with a tab per category, mirrored to Google Sheets. It runs in the background on n8n, so it keeps going after the laptop is closed, and the rows collected so far can be downloaded at any moment; large sites are split into parts. Each page fetch escalates only as far as it needs, from a direct request to a proxy pool, a scraping API, and finally a full renderer. Extraction reads JSON-LD and tables first, falling back to chunked, parallel AI extraction. A small web interface shows live progress, a time estimate, a preview of the rows, and pause, resume, cancel, and restart controls.

The automation behind it

LiveUniversal Web ScraperAI scraping engine

One link in, the whole site out. A shared engine fetches pages and escalates only as far as it must, reads structured data before it spends anything on AI, and writes the rows into a spreadsheet. Quick jobs and long crawls run as separate, controllable workers.

What it handles

  • One engine, called as a sub-workflow by both the quick runner and the crawl worker
  • The AI call is skipped entirely when structured data already answers the page
  • The crawl worker locks each job, opens a new sheet when a part fills up, and writes one tab per category
  • Pause, resume, cancel, restart and delete, routed through a single control endpoint
Trigger
Web app (webhook) and a crawl schedule
