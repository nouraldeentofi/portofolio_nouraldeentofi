CV Screener

AI CV screening for Arabic and English CVs

AI SaaS product2026

Upload a folder of CVs and every one is read, classified, and scored by AI, with each point traced to a quote from the CV.

Visit live site (opens in a new tab)

The problem

HR teams receive hundreds of CVs per opening, many of them Arabic PDFs that most tools cannot read. Screening them by hand is slow and inconsistent, and an AI score with no explanation is not something a recruiter can trust or defend.

What I built

A full-stack, Arabic-default bilingual product. HR uploads files, folders, or ZIPs; a background worker extracts the text (repairing Arabic visual order), and n8n profiles each CV, places it in the account's own categories, and scores it on several dimensions with quoted evidence. The server verifies every quote against the CV before it can raise a score, and computes every number people sort by. On top sit filters on every profile field, Arabic and English full-text search, HR status, stars and notes, role screenings with weighted criteria and must-haves, AI summaries of any scope, CSV export, and an admin console.

The automation behind it

LiveCV Screener agentsAI agents behind a product

The AI engine of CV Screener: sibling agents that profile one CV, screen one CV against a job, and summarise a whole pool. The product server calls them; every one checks a secret first, fences the CV as data, and returns typed JSON or a typed error.

What it handles

  • A secret header is checked before anything else; a bad call never reaches the model
  • The CV text is wrapped in random fences, so instructions hidden inside a CV are read as data
  • The model scores with quoted evidence; weighted totals and must-have caps are computed in code
  • Set not to store executions, because CVs are personal data
